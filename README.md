# 森林冰火人 · 3D 元素神殿

使用原生 WebGL 制作的三关合作冒险游戏，无需构建或安装依赖。

## 操作

- 火人：WASD 移动，空格跳跃。
- 冰人：方向键移动，Enter 跳跃。
- 手机：触控方向键、跳跃和切换角色。
- R 重新开始，Esc 暂停。

收齐同色宝石，点亮两座元素祭坛，分别进入同色出口即可通关。火人可通过熔岩，冰人可通过冰池，双方都需避开毒池。

## 部署

静态文件在 `docs/`。GitHub Pages 发布来源选择 `main` 分支的 `/docs` 文件夹，之后推送会自动更新。
